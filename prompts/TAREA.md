# Tarea individual - Prompt avanzado

## 1. Problema elegido

Diseñar las clases de un sistema de notas en Java para una institución educativa.

El sistema debe permitir registrar estudiantes, cursos y notas, además de calcular promedios.

---

## 2. Versión 1 - Prompt básico

```text

Diseña las clases necesarias para un sistema de notas en Java. Indica los atributos de cada clase y genera el código de la clase Estudiante.

```
